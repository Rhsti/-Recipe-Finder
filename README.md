# Recipe Finder 🍽️

## About the Project
Recipe Finder is a responsive web application that helps users discover recipes, search for meals, and save their favourite dishes.

## Live Demo
[**Try Recipe Finder**] (https://courageous-daffodil-005fd5.netlify.app/)

## Features
- **Browse Recipes:** Explore recipes with images and basic information.
- **Search:** Find recipes by name, ingredients, or meal type (breakfast, lunch, or dinner).
- **Filter:** Filter recipes by difficulty (Easy, Medium, or Hard).
- **Recipe Details:** View ingredients and cooking instructions.
- **Favourites:** Save and remove favourite recipes.
- **Local Storage:** Keep favourites saved after refreshing the page.
- **Responsive Design:** Works on desktop, tablet, and mobile.
- **API Handling:** Display loading and error messages.

## API
The project uses the [DummyJSON Recipes API](https://dummyjson.com/recipes) to retrieve recipe data using `fetch()` and `async/await`.

## How to Run Locally
1. Clone or download the repository.
2. Open the project in Visual Studio Code.
3. Run it using Live Server.
4. Open the website in your browser.

An internet connection is required to load recipes.
